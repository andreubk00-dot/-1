# Тихая долина · 0.9.0-rc.1

Этот кандидат фиксирует текущий объём игры перед дальнейшей проверкой выпуска. Он не означает прохождение модерации площадки или тестирование на физических телефонах.

## Состав

- Мир 80×56: усадьба, лес, озеро, кряж; общие дороги и карта без телепортации.
- Две культуры, продажа урожая, склад, мастерская, доски, ящики, медные слитки, три уровня инструментов.
- Рыбалка с реакцией, ягоды и еда, дождевой полив, восстановление диких ресурсов.
- Три жителя с разовыми поручениями, ежедневные заказы, общая шкала опыта.
- Свободные 24 ячейки инвентаря и 10 ячеек хотбара, иконки, перетаскивание и сенсорное назначение.
- Старые сохранения, предохранение повреждённого слота, автосохранение и сохраняемая настройка звука.

## Воспроизводимая проверка

```bash
./tools/make-art.sh     # только при изменении графики; Python 3 + Pillow
./tools/build-web.sh    # импорт, 175 проверок Godot, Web-экспорт, ZIP
./tools/serve-web.sh    # отдельный терминал, http://127.0.0.1:8765
npm ci
npm run test:web        # 100 проверок в пяти браузерных сериях
```

Godot 4.6.3, Chromium, WebGL через программный SwiftShader. Тесты работают с настоящей WebAssembly-сборкой, экранными окнами и сохранениями. Мобильные сценарии отправляют настоящие touch-события в эмуляции Chromium. Фикстуры перемещают персонажа между точками через тестовое сохранение; в игре такой функции нет. SDK Яндекса в тестах эмулируется.

Особенно проверяются: отсутствие частичного списания, повторных наград и двойного улова; перенос старых грядок и раскладок; доступность всех жителей по дорогам; защита построек и грядок при восстановлении ресурсов; остановка таймера в окнах и паузе; восстановление всех новых данных после повторного входа. Архив сверяется с экспортом, после публикации выполняется отдельная проверка действующего сайта.

## Перед стабильным выпуском

Нужны проверка продолжительных сессий и экономики, физические Android/iOS с разным объёмом памяти, звук после сворачивания и смены ориентации, реальный SDK и черновик в кабинете Яндекс Игр. Облачная синхронизация, авторизация, реклама и лидерборды не реализованы. Прогресс остаётся в данных конкретного браузера на прежнем домене.

Жители имеют фиксированные стоянки; нет сезонов, животных, боёв, интерьеров и мультиплеера. Это ограничения текущего объёма выпуска. Активная рыбалка после повторного входа отменяется; стоимость заброса не возвращается. Браузерная эмуляция и автоматические тесты не заменяют проверку на реальных устройствах.
