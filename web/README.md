# Браузерная сборка и публикация

Игра использует Godot 4.6.3 → WebAssembly / WebGL 2. Переписывать её для разных площадок не требуется: правила игры остаются в Godot, интеграция с площадкой изолирована в `web/platform.js`. Архив сборки — `dist/quiet-valley-web.zip`; внутри `index.html` расположен прямо в корне.

## Собрать и запустить

Нужен Godot **4.6.3** и официальные Export Templates той же версии. Установите их через меню Godot: Editor → Manage Export Templates. В текущей облачной среде шаблоны уже установлены; архив получен из официального релиза, SHA-512 сверена с официальным SHA512-SUMS.txt.

```bash
./tools/build-web.sh
./tools/serve-web.sh
```

Откройте локальный адрес, напечатанный сервером (порт 8765). Остановка сервера — Ctrl+C. Для другого порта: `PORT=8080 ./tools/serve-web.sh`. Открывать HTML как файл через `file://` нельзя: WASM и пакет игры загружаются по HTTP.

Web-экспорт работает без потоков и GDExtension, поэтому SharedArrayBuffer и заголовки COOP/COEP не требуются. Двумерные PNG используют обычные текстуры, без обязательного сжатия S3TC/ETC2. На внешнем хостинге используйте HTTPS, отдавайте `.wasm` с `Content-Type: application/wasm`, `.js` как JavaScript. Для собственных обновлений настройте сброс кэша HTML/JS/PCK/WASM, чтобы старый загрузчик не смешивался с новой сборкой.

## Яндекс Игры

1. Создайте черновик игры в кабинете разработчика Яндекс Игр.
2. Загрузите **`quiet-valley-web.zip`**, без дополнительной внешней папки в архиве.
3. Укажите русский язык, управление клавиатурой/мышью и сенсорное управление. Для мобильных устройств удобнее альбомная ориентация.
4. Запустите черновик в тестовом режиме площадки. Проверьте загрузку SDK, начало игры, меню, сворачивание, звук, сохранение и повторный вход. Проверьте также на настоящем телефоне.
5. Подготовьте карточку игры: описание, собственную иконку и скриншоты. Иконка включена в проект, браузерные скриншоты находятся в `tests/web-*.png`.
6. После проверки отправьте игру на модерацию через кабинет. Размещение и одобрение платформой не выполняются локальной сборкой.

Режим Яндекс Игр определяется по домену страницы или referrer площадки; принудительный переключатель для тестирования — `?platform=yandex`. В этом режиме загружается предоставляемый площадкой `/sdk.js`, затем вызывается `YaGames.init()`. На обычном хостинге SDK не запрашивается, игра работает самостоятельно. Переключатель не даёт доступ к SDK вне площадки: локально этот endpoint нужно эмулировать, как делают тесты.

Реализованы:

- `LoadingAPI.ready()` после готовности сцены, один раз;
- `GameplayAPI.start()` после нажатия «Войти в долину» и возобновления игры;
- `GameplayAPI.stop()` в меню, при потере фокуса, скрытии вкладки и паузе SDK;
- события `game_api_pause` / `game_api_resume`;
- остановка симуляции, блокировка действий и выключение звука во время паузы;
- экран повторной попытки при ошибке загрузки или инициализации SDK;
- отсутствие рекламы до явного проектирования соответствующей механики.

**SDK проверен с эмуляцией в Chromium. Реальная интеграция в кабинете, требования модерации и прохождение модерации пока не проверены.** Перед публикацией сверьте текущие требования в кабинете и [официальной документации](https://yandex.ru/dev/games/doc/ru/sdk/sdk-about).

## Другие площадки

Тот же ZIP можно размещать на обычном HTTPS-хостинге или площадке, принимающей HTML5-игры. Специфические SDK, реклама, лидерборды и требования каждой площадки подключаются отдельно через `platform.js`. Архив не содержит сервера и не требует Node.js у игрока.

## Сохранения

В браузере используется `localStorage`, ключ `quiet-valley:v1:user://farm_v1.json`. Запись выполняется после успешных игровых действий, по F5, каждые 30 секунд, при потере фокуса и скрытии/закрытии страницы. Сохранение не зависит от завершения фоновой синхронизации IndexedDB. Состояние дополнительно проверяется при загрузке. Формат данных 2 принимает формат 1, сохраняя прежний ключ. Запись грядки теперь содержит пятое поле — вид культуры; старые четырёхполевые грядки считаются репой. Данные ежедневных заказов сохраняются вместе с фермой.

Прогресс привязан к браузеру и origin, очистка данных сайта его удаляет. Синхронизация между устройствами, авторизация и облачные сохранения Яндекса **не реализованы**. В приватном режиме или при запрете хранилища игра сообщает, что сохранение не удалось, и продолжает работать. Повреждённый основной слот не перезаписывается: сессия использует `quiet-valley:v1:user://farm_recovery.json`.

## Сенсорное управление

Экранные стрелки удерживаются для движения; E выполняет действие перед персонажем. Предметы выбираются касанием хотбара. Инвентарь открывается кнопкой с рюкзаком справа: выберите предмет и затем ячейку хотбара. Экранные стрелки скрываются на время работы с окном; закройте его кнопкой X. Можно также нажать на соседнюю клетку. Отпускание, отмена касания и потеря фокуса сбрасывают движение. При вертикальном положении показывается совет повернуть устройство; блокировки запуска нет.

## Проверки

```bash
./tools/test.sh        # 175 проверок правил игры и сохранения в Godot
npm ci                # Playwright; для запуска игры npm не требуется
# При отсутствии системного Chromium: npx playwright install chromium
./tools/serve-web.sh  # отдельный терминал
npm run test:web
```

`GAME_URL` задаёт адрес тестируемой сборки, `CHROMIUM_PATH` — браузер. **100 браузерных проверок** прошли в Chromium. Тесты открывают настоящую WASM-сборку, работают с игровым canvas и читают получившиеся сохранения. SDK эмулируется перехватом `/sdk.js`; реальная сеть Яндекса в тестах не используется. Мобильный ввод проверяется настоящими событиями touch в мобильной эмуляции Chromium, что не заменяет проверку на реальных Android/iOS устройствах.

В архив включены лицензионные уведомления Godot, его зависимостей и шрифта DejaVu. Рекламные идентификаторы, ключи и секреты для текущей сборки не нужны.

## Обновление текущего сайта

Публичная игра: https://andreubk00-dot.github.io/-1/ . При подготовке новой версии сначала выполните сборку и все пять браузерных серий тестов. Команда ниже публикует содержимое готового архива в существующую ветку `gh-pages` репозитория origin:

```bash
./tools/publish-pages.sh
```

Скрипт не пересобирает игру и не заменяет проверки. При конфликте push останавливается без force. Файлы новой версии имеют отпечаток содержимого в имени; предыдущая такая версия сохраняется для клиентов с закэшированным HTML. Открытые игровые вкладки нужно обновить, чтобы перейти на новую версию. Прогресс остаётся в том же localStorage на том же домене.

## Интерфейс и сохранения 0.9 RC1

Инвентарь и хотбар сохраняются в полях `inventory_layout`, `hotbar`, `active_slot` прежнего слота localStorage. Это представление предметов; сами количества по-прежнему хранятся в `bag`. Назначение предмета на хотбар не создаёт дополнительный стек. Некорректные настройки интерфейса восстанавливаются отдельно от прогресса фермы.

Браузерные тесты `tests/hud.web.test.cjs` проверяют реальное перетаскивание, обмен местами, назначение и очистку, клавиши/колесо, восстановление после перезагрузки и сенсорное управление. `tests/hotbar_test.gd` проверяет модели раскладок, совместимость и фазы рабочего действия. Визуальные снимки: `tests/hud-v3.png`, `tests/inventory-v3.png`, `tests/inventory-mobile-v3.png`, `tests/chop-v3.png`, `tests/water-v3.png`.

Строительство открывается отдельной вкладкой или B и не назначается на хотбар. При переносе старого сохранения убирается только прежний предмет `build`, остальные позиции сохраняются. J открывает заказы. Проверки `tests/expansion_test.gd` и `tests/expansion.web.test.cjs` охватывают миграцию, размещение и отмену постройки, морковь, полный цикл четырёх политых дней, сдачу заказа и повторный вход. Новые снимки: `tests/construction-v4.png`, `tests/inventory-v4.png`, `tests/orders-v4.png`, `tests/farm-v4.png`.

Чтобы воспроизвести все PNG/WAV, запустите `./tools/make-art.sh` (Python 3 и Pillow). Скрипт выполняет генераторы в правильном порядке; для игры и публикации генерация не нужна.

В том же формате 2 появился необязательный блок `frontier`: выполненные поручения, дни сбора ягод, посещённые районы и число уловов. Сохранения 1/2 без него получают ресурсы новых районов один раз; прежняя ферма, здания, грядки и пользовательские раскладки сохраняются. Новые предметы `berry`, `fish`, `ore`, `ingot` получают нулевые значения при переносе. Настройка звука хранится в `muted`. Активная поклёвка не сохраняется: после повторного входа заброс нужно выполнить заново, уже потраченная энергия остаётся потраченной.

`tests/frontier.web.test.cjs` проходит настоящие окна карты и жителей, переплавку и выдачу меди, разовые награды, сбор и употребление ягод, рыбалку с паузой, дождь, повторный вход, назначение удочки касанием и рыбалку экранной кнопкой E. Плашка района сверху открывает карту касанием, не перекрывая E. Переключение звука доступно в справке. Проверка мобильных размеров выполняется эмуляцией, без заявления о тестировании настоящих телефонов.
